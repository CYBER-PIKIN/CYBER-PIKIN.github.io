Security Headers Analyzer

Review HTTP response headers against a practical baseline, see which protections are present, and get remediation guidance. Paste the response headers from a site or a lab you are authorized to assess.

Runs locally in your browser No target requests

1. Paste response headers

Paste header lines only, for example content-security-policy: default-src 'self'. Header names are case-insensitive. This tool evaluates the text you provide; it does not verify a live server.

Important: This is a lightweight configuration review, not a full security audit. A present header can still be weak or incorrectly configured. Review application compatibility and the full policy before making production changes.

Methodology

The analyzer checks for Content-Security-Policy, Strict-Transport-Security, X-Content-Type-Options, clickjacking protection through X-Frame-Options or CSP frame-ancestors, Referrer-Policy, and Permissions-Policy. Each check has a simple weight and actionable guidance. The result is a learning aid, not a formal compliance rating.
